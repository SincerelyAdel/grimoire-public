**`uvm_object`** — base class for all UVM data and for everything else in the library

The root of the UVM class tree. It gives every object a name, a type name, a unique instance ID and a standard set of utility operations: create, clone, copy, compare, print, pack and record. Transactions, sequences and configuration objects extend it directly or through `uvm_sequence_item`; components extend it through `uvm_report_object`.

**Declaration**

```systemverilog
virtual class uvm_object extends uvm_void;
    function new(string name = "");
```

**Main methods**

| Method | Purpose |
| --- | --- |
| `get_name()` / `set_name(string)` | Instance name |
| `get_full_name()` | For plain objects the same as `get_name()`; components return the hierarchical path |
| `get_type_name()` | Type name string, generated by the `` `uvm_*_utils `` macros |
| `get_inst_id()` | Unique integer per object |
| `create(string name = "")` | New object of the same type |
| `clone()` | `create()` followed by `copy()`; returns `uvm_object`, so `$cast` the result |
| `copy(uvm_object rhs)` | Deep copy; calls the user hook `do_copy` |
| `compare(uvm_object rhs, uvm_comparer comparer = null)` | Deep compare; calls `do_compare` |
| `print(uvm_printer printer = null)` / `sprint(...)` | Formatted dump; calls `do_print` |
| `convert2string()` | One-line string; user-defined, empty by default |
| `pack` / `pack_bytes` / `pack_ints`, `unpack...` | Serialize to and from bits; call `do_pack` / `do_unpack` |
| `record(uvm_recorder recorder = null)` | Transaction recording; calls `do_record` |

**Example**

```systemverilog
class fifo_cfg extends uvm_object;
    `uvm_object_utils(fifo_cfg)

    int unsigned depth = 16;
    bit          has_coverage = 1;

    function new(string name = "fifo_cfg");
        super.new(name);
    endfunction

    virtual function void do_copy(uvm_object rhs);
        fifo_cfg rhs_;
        super.do_copy(rhs);
        if (!$cast(rhs_, rhs)) `uvm_fatal("FIFO_CFG", "do_copy: type mismatch")
        depth        = rhs_.depth;
        has_coverage = rhs_.has_coverage;
    endfunction

    virtual function string convert2string();
        return $sformatf("depth=%0d has_coverage=%0b", depth, has_coverage);
    endfunction
endclass
```

**Notes**

- Never override `copy`, `compare` or `print` themselves; override the `do_*` hooks, or use the field macros.
- Objects are not part of the component hierarchy and take no part in phasing.
- `clone()` needs `create()`, which the `` `uvm_object_utils `` macro provides.

**See also**: `uvm_object_utils`, `uvm_sequence_item`, `uvm_component`, `do_copy`, `do_compare`, `convert2string`, `clone`
